# 全网科研经验汇编（实操版：只收「术」）

> 汇编日期：2026-09-09（第三版）。只收可执行的「术」，不收「道」。每条带「操作：」。
> 来源可靠性：**A 级（全文已核）** = Keshav《How to Read a Paper》（ACM SIGCOMM，李沐三遍法的英文原典）、NeurIPS 2024 官方《Reviewer Guidelines》、Karpathy《A Survival Guide to a PhD》；**B 级** = SPJ《How to write a great research paper》（官方页已核）。

## 一、读论文的术（博士没讲过，全是增量）

**1. 三遍法**（Keshav，A 级）
- **第一遍（5~10 分钟）**：只看 ①标题+摘要+引言 ②章节标题 ③结论 ④扫一眼参考文献。
- 结束后必须能回答 **5C**：Category（哪类论文）/ Context（和哪些相关）/ Correctness（假设成立吗）/ Contributions（贡献是什么）/ Clarity（写得好吗）。
- 第一遍过不了的，果断不读。
- **第二遍（最多 1 小时）**：精读图（坐标轴标了没？有没有误差棒？——这是区分「赶工」和「认真」的地方）；标记没读过的参考文献留作后续。
- **第三遍（新手 4~5 小时）**：**在脑中虚拟重做一遍**——用作者的假设重建工作，对比原论文，就能定位创新点、也定位隐藏的假设和缺陷。
- 操作：看一篇论文前先决定「读到第几遍」，别一上来从头啃到尾。

**2. 文献调研法**（Keshav，A 级）
- 操作：Google Scholar + 3~5 个关键词 → 找 **3~5 篇近期论文** → 每篇只做第一遍 → **只读它们的 related work 段**（那里有领域的缩略综述）→ 顺藤摸到关键论文和会议 → 再决定谁值得进第二、三遍。

**3. 反向写作金句**（Keshav，A 级——这是读论文法倒过来当写作法用）
> 「审稿人和读者**只会读一遍**。标题和摘要必须一遍就让人抓住要点；一遍看不懂 → 被拒 / 没人读。」
- 操作：交稿前自己用「第一遍 5 分钟」读自己的论文，问 5C；答不上来的段落就是败笔。

## 二、按审稿人视角写作的术（最值钱的一节）

**4. 审稿人打分的四个维度**（NeurIPS 2024 官方 Reviewer Guidelines，A 级——写论文时逐条自查）：

| 维度 | 审稿人问的问题 | 写论文时的自查 |
|---|---|---|
| **Originality** | 任务/方法新吗？**已有技术的新组合也算贡献**？与已有工作区别清楚吗？引用够吗？ | gap 段必须写清「我和 G2IA/VGGT-MPR 的机制差异」 |
| **Quality** | 技术可靠吗？主张有实验支撑吗？完整还是半成品？**诚实评估自己优缺点了吗？** | 实验做全；limitations 段照实写 |
| **Clarity** | 写得清吗？组织好吗？**专家读者能否复现？** | 按可复现标准写方法细节 |
| **Significance** | 结果重要吗？别人会 build on 吗？有独特数据/结论/方法吗？ | 明确「谁会在什么场景用我这个重排」 |

- 三个数值评分：**Soundness（技术可靠性）/ Presentation（表达）/ Contribution（贡献）**，各 1~4 分。写作前先自评这三个分。

**5. 审稿指南里的三条金句（直接翻译成操作）**（NeurIPS，A 级）：
- 「checklist 答 no 通常不是拒稿理由；**诚实写 limitations 的作者应被奖励而非惩罚**」→ 操作：论文必须有一段 Limitations，照实写（我们就要写：跨模态鸿沟、小数据集、rel_depth 依赖单目深度估计）。
- 「limited evaluation 是 borderline reject 的常见理由」→ 操作：实验至少覆盖主结果 + 消融 + 泛化，别只有一张表。
- 「满分论文的标准：专家读者能照着复现」→ 操作：方法段写到「照抄能重做」的程度，代码开源。

## 三、写作流程与细节的术（Karpathy A 级 / SPJ B 级）

**6. 先写论文，再补实验**（SPJ）
- 操作：实验做到 6~7 成就开始写全文骨架；写作会逼出「缺哪个实验」→ 列清单回头补。现在就可以搭 IJCNN 8 页骨架，按 2027-01-31 倒排。

**7. 内部截稿提前两周**（Karpathy）
- 操作：正式截稿前 14 天交完整草稿（所有实验都要有、数字可以没调），走一遍正式评审流程，逼出缺的关键实验。

**8. 一篇论文只卖一个贡献**（Karpathy，用自己的失败案例证明）
- 操作：动笔前写一句话「本文唯一贡献是 ___」。第二个想法另写一篇，别塞进来。
- 与博士「三个贡献点」不冲突：那是**一个贡献的三个子点**（新问题/新机制/新评测），不是三个独立贡献。

**9. intro 五步公式**（Karpathy）
- 操作：①X 是重要问题 → ②挑战是 A、B → ③已有工作用 Y 解决、但有问题 Z → ④我们做 W → ⑤W 有这些性质、实验证明。第②步列的挑战必须正好是你后面解决的。

**10. 方法节每步四件事**（Karpathy）
- 操作：每一小段必须有 ①在干什么 ②难点 ③别人怎么做 ④我为什么这么做。缺④就是流水账，重写。

**11. 论文「模样」规格**（Karpathy）
- 操作：intro 约 1 页；related work 约 1 页、引用密度适中；第 1~2 页一张 pull figure；第 3 页一张系统图；结果表数字多、好的加粗；正文恰好写满页数上限。

**12. 用词黑名单**（Karpathy）
- 操作：禁 study/investigate（用 propose/develop）；禁 combine/modify/expand（增量词）；禁 pipeline/system（用 model/method）；禁 features（用 representations）。

**13. 相关工作最后写 + 例子先行**（SPJ）
- 操作：related work 段最后写；每个新概念先给例子再给形式定义。

**14. 给未来的自己写 readme**（Karpathy）
- 操作：每个实验目录放 readme.txt（怎么跑、参数、坑）。camera-ready 阶段必回头用。
