# 选题门（GATE v2）

> 用途：任何候选方向在进入 IDEA / LANDSCAPE / BASELINE 之前，必须逐条通过本门。源自博士《科研决策规则与经验汇编》 + 项目 AGENTS.md 规则，把「查重、数据、基线、证伪、资源」固化成可执行闸门。
> 建立日期：2026-09-11（因「跨模态地点检索 + 候选重排」方向在 D-015 终止后重建）。

## 判定总则

- 一条不过 → 该方向淘汰，不进入下一阶段，不沉没成本。
- 任何「已验证 / 有效 / 优于」的表述必须能追溯到文件、命令、日志和指标。
- 查重结论必须以证据等级标注（A 读全文 / B 官方元数据摘要 / C 二手 / D 推断），仅 C/D 不得作为立项依据。

## G1 真实 gap（主张级查重）

- 完全没人做 → 伪需求，淘汰。
- 太多人做 → 拥挤，淘汰。
- 目标：找「刚开始有人碰」的中间地带。
- 主要论文必须全文核验（目标 A 级），gap 能用一句话说清。
- 判据：换个更强 backbone 你的方法还成立吗？若成立说明方法层有贡献；若不成立说明只是拼模块。

## G2 公开数据

- 公开数据集、许可清晰、能实际下载。
- 同任务下能找出 N 个现成模型可复用（开源数据集 → N 模型）。
- 数据划分（train/val/test）能冻结，且测试集不得在调参阶段被查看。

## G3 开源基线

- 至少一个开源 baseline，且能复现。
- 不接受「无代码」的 baseline（博士：不开源很难复现、数据未必真实）。
- baseline 必须在本机/租用环境成功跑通后，才能进入方法改造。

## G4 最小证伪实验（表 0 / 最小反例）

- 能设计一个最小的证伪实验，预先定义通过标准（不是跑完再定）。
- 在 20% 子集（甚至更小）先跑，通不过 → 全量也不行 → 淘汰。
- 负结果必须记录淘汰理由，不删运行记录。

## G5 资源边界

- 单卡算力够（目标 CCF-C 级别、预算一两百块）。
- 周期够、目标会议明确（截稿日期、页数、主题匹配、AI 使用政策）。
- 创新性与可操作性负相关，优先「一定创新 + 好操作」。

## 通过后进入的阶段

G1+G5 全过 → IDEA（写 idea 报告 + 选题红队独立否决）
→ 红队通过 → BASELINE（复现开源 baseline）
→ 方法改造 → 20% 子集验证 → 全量 → 写作。
